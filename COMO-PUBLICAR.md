# Como colocar o aplicativo no celular (resumo)

Os arquivos desta pasta formam o aplicativo inteiro. Eles não contêm nenhum dado da sua
biblioteca, só o programa.

1. **Publicar no GitHub Pages:** envie todos os arquivos desta pasta para o repositório
   `Biblioteca` e ligue o Pages em Settings › Pages, com a branch `main` e a pasta `/ (root)`.
   O endereço fica `https://SEU-USUARIO.github.io/Biblioteca/`.
2. **Instalar:** abra o endereço no celular. No Android, menu do Chrome › Instalar aplicativo.
   No iPhone, botão compartilhar do Safari › Adicionar à Tela de Início.
3. **Trazer os dados:** na primeira abertura, escolha o `Biblioteca.html` do OneDrive, ou ligue o
   OneDrive em Configurações para sincronizar sozinho.
4. **Backup:** em Configurações › Cópias e backup, use **Baixar o arquivo da biblioteca**.

Um aviso sobre o `sw.js`: ele agora só apaga os arquivos offline da própria biblioteca. Se você
publicar outro aplicativo no mesmo endereço do GitHub, os arquivos dele não são mais apagados
quando a biblioteca é atualizada.

O passo a passo completo, incluindo a sincronização com o OneDrive, está no PASSO-A-PASSO.md.
